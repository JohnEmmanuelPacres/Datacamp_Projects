# Datacamp Projects

This repository contains various data science, machine learning, and SQL projects completed on DataCamp.

## Structure

The repository is organized into the following categories:

### Machine Learning
* [**Analyzing Car Reviews with LLMs**](./Machine%20Learning/Analyzing%20Car%20Reviews%20with%20LLMs): Project involving the analysis of car reviews using Large Language Models.
* [**Clustering Antarctic Penguin**](./Machine%20Learning/Clustering%20Antarctic%20Penguin): A clustering project to group penguin species in Antarctica based on their characteristics.
* [**Developing Multi-input Models for OCR**](./Machine%20Learning/Developing%20Multi-input%20Models%20for%20OCR): Project focused on creating multi-input machine learning models for Optical Character Recognition.
* [**Predicting Movie Rental Durations**](./Machine%20Learning/Predicting%20Movie%20Rental%20Durations): Predictive modeling to estimate how long a movie will be rented.
* [**Predictive Modeling for Agriculture**](./Machine%20Learning/Predictive%20Modeling%20for%20Agriculture): Project applying predictive modeling techniques to agricultural data.

### SQL
* [**Analyzing Motorcycle Part Sales**](./SQL/Analyzing%20Motorcycle%20Part%20Sales): SQL project analyzing sales data for motorcycle parts to gain business insights.
* [**Analyzing Student's Mental Health**](./SQL/Analyzing%20Student's%20Mental%20Health): SQL project exploring and analyzing data related to students' mental health.
* [**Investigating Netflix Movies**](./SQL/Investigating%20Netflix%20Movies): Data exploration and analysis of a Netflix movies dataset using SQL.
